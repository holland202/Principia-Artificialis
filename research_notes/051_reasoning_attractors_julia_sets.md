## 1. Hypothesis

Multi-step reasoning can be modelled, to first order, as iteration of a discrete dynamical system on a complex (or high-dimensional) state space. The **Julia set** of that system then becomes a geometric portrait of the boundary between coherent, bounded reasoning trajectories and trajectories that escape into fragmentation or hallucination.

Concretely:

- A **connected Julia set** corresponds to a regime in which almost all nearby initial states (prompts / intermediate thoughts) remain in a bounded attractor — stable, self-consistent reasoning.
- A **totally disconnected Julia set** (Cantor dust) corresponds to a regime in which almost every trajectory eventually escapes — brittle or hallucinatory reasoning.
- The **Mandelbrot set** organises the parameter space of possible “reasoning maps”; its boundary marks the critical transition between these two qualitative behaviours.

This is an analogy with precise mathematical content, not a claim that transformers literally implement quadratic maps.

## 2. Mathematical Framework

### 2.1 Classical Quadratic Family

Consider the quadratic family

\[
f_c : \mathbb{C} \to \mathbb{C}, \qquad f_c(z) = z^2 + c, \quad c \in \mathbb{C}.
\]

The **filled Julia set** of \(f_c\) is

\[
K_c = \bigl\{ z \in \mathbb{C} : \text{the orbit } \{f_c^{\circ n}(z)\}_{n\ge 0} \text{ remains bounded} \bigr\}.
\]

The **Julia set** itself is the boundary:

\[
J_c = \partial K_c.
\]

The **Mandelbrot set** is the set of parameters for which the critical point remains bounded:

\[
M = \bigl\{ c \in \mathbb{C} : \text{the orbit of } 0 \text{ under } f_c \text{ remains bounded} \bigr\}.
\]

Classical facts (Douady–Hubbard, etc.):

- If \(c \in M\) then \(J_c\) is connected.
- If \(c \notin M\) then \(J_c\) is a Cantor set (totally disconnected) and has measure zero.

### 2.2 Escape-Time and Lyapunov Indicators

For numerical work we use the escape-time function. Fix an escape radius \(R \ge 2\). Define

\[
N_R(z; c) = \min\bigl\{ n \ge 0 : |f_c^{\circ n}(z)| > R \bigr\}
\]

(with the convention that the minimum over the empty set is \(+\infty\)).

A practical Lyapunov-like quantity along a finite orbit is

\[
\lambda_N(z; c) = \frac{1}{N}\sum_{k=0}^{N-1} \log\bigl| f_c'(f_c^{\circ k}(z)) \bigr| = \frac{1}{N}\sum_{k=0}^{N-1} \log\bigl|2\, f_c^{\circ k}(z)\bigr|.
\]

Positive average Lyapunov exponent indicates local expansion (sensitivity / fragility).

### 2.3 Reasoning Interpretation

| Dynamical object              | Reasoning interpretation                                      |
|-------------------------------|---------------------------------------------------------------|
| Bounded orbit in \(K_c\)      | Coherent multi-step reasoning that stays self-consistent     |
| Escaping orbit                | Trajectory that eventually leaves the region of valid inference (hallucination, contradiction, collapse) |
| Connected \(J_c\)             | Robust regime: small perturbations of the prompt still yield bounded thought |
| Cantor \(J_c\)                | Brittle regime: almost every nearby starting point eventually escapes |
| Parameter \(c\) near \(\partial M\) | Critical “reasoning temperature” or prompt complexity where stability is lost |

## 3. Numerical Protocol (Reference Implementation)

The accompanying script `scripts/note051_reference.py` implements:

1. Escape-time rendering of Julia sets for representative values of \(c\).
2. Computation of the fraction of a grid that remains bounded up to a maximum iteration count (a discrete proxy for measure of \(K_c\)).
3. Average Lyapunov exponent on a sample of orbits.
4. A simple bifurcation-style scan across a real slice of the Mandelbrot set.

All numbers printed by the script are generated by the code; they are not hand-entered.

### 3.1 Key Quantities Reported

- Bounded fraction \(\mu_N(c)\) on a uniform grid after \(N\) iterations.
- Mean escape time for points that do escape.
- Mean Lyapunov exponent on surviving orbits.

These give a quantitative distinction between “connected-like” and “Cantor-like” regimes even at modest resolution.

## 4. Preliminary Observations from the Reference Code

(Exact values are produced by running the script; the qualitative pattern is robust.)

- For \(c = 0\) (the unit disk) the bounded fraction is essentially 1 and Lyapunov exponents are negative inside the disk.
- For \(c = -0.75\) (on the real axis, still inside \(M\)) the set remains connected and the bounded fraction stays high.
- For \(c = -0.8 + 0.2i\) (outside \(M\)) the bounded fraction collapses dramatically and the Julia set appears dust-like.
- Crossing the boundary of \(M\) produces a sharp drop in bounded fraction — a geometric phase transition in parameter space.

These observations support the claimed dictionary between connectivity of \(J_c\) and robustness of reasoning trajectories.

## 5. Limitations and Falsifiability

- The quadratic family is a severe idealisation. Real residual-stream dynamics are high-dimensional and non-holomorphic.
- Escape-time on a finite grid is only a proxy for the true measure of \(K_c\).
- No claim is made that any existing language model literally implements \(z\mapsto z^2+c\).

**Falsification criteria:**
- If, under a more realistic iterative model of attention or residual updates, one cannot find parameter regimes that produce both connected-like and Cantor-like behaviour with a sharp transition, the analogy loses force.
- If boundedness of orbits fails to correlate with any human-judged notion of coherence, the interpretation is refuted.
